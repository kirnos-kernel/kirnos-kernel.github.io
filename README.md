## Overview

KirnOS is an open operating system project exploring a capability-oriented kernel, portable hardware layers, a native filesystem, and a developer surface designed around Kirn.

## Local development

This is a static GitHub Pages website. No build step is required. Serve the repository locally with:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.
